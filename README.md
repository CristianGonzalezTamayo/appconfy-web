# appconfy.com

Páginas legales de Confy publicadas con GitHub Pages: política de privacidad,
eliminación de cuenta y "correo confirmado".

- Fuente de la política: `fuentes/politica.md` (copia de `POLITICA_DE_PRIVACIDAD.md` del repo de la app).
- Regenerar: `python build.py`.
- Dominio: archivo `CNAME` (`appconfy.com`).
